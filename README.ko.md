# Doumi

[English](README.md) · **한국어**

Doumi(도우미)는 AI 서비스를 활용해 운영 중인 웹서비스와 API의 취약점을 점검하는 AI 웹취약점 점검 에이전트입니다. 고객 PC나 사내 서버에 설치한 에이전트가 승인된 대상만 점검하고, AI가 결과마다 판정을 제안하면 담당자가 결정합니다. [한비엣테크](https://hanvietech.com)가 개발하고 있습니다.

> **개발 중인 제품입니다.** 이 저장소는 제품 소개를 담은 공개 문서이며, 제품 소스코드는 공개하지 않습니다. 소개된 기능과 구성은 개발 과정에서 달라질 수 있습니다.

## 서비스 흐름

1. **대상 확인**: 점검할 웹서비스가 고객사 소유인지 먼저 확인합니다. 확인 전에는 점검하지 않습니다.
2. **범위 안의 점검**: 에이전트가 정해진 범위·속도·시간 안에서 웹서비스와 API를 점검합니다.
3. **AI·사람의 판정**: AI가 진짜 문제·오탐·검토 필요를 근거와 함께 제안하고, 담당자가 결정합니다.
4. **조치·재검증**: 조치한 문제만 다시 점검해 해결됐는지 확인합니다. 해결되지 않은 문제는 다음 점검에서 계속 추적합니다.

## 주요 특징

- **승인된 대상만, 정해진 범위 안에서**: 소유가 확인된 웹서비스만 점검하고, 범위·속도·시간 한도는 에이전트가 직접 지킵니다. 운영 환경은 공격 요청 없이 관찰만 합니다.
- **어디까지 점검했는지 보여 줍니다**: 로그인 실패나 중단으로 점검이 부족했다면 '취약점 없음'이 아니라 '점검 불충분'으로 표시합니다.
- **결과는 하나로, 결정은 사람이**: 여러 점검 결과를 같은 문제끼리 하나로 모으고 신규·재발·해결을 추적합니다. AI의 판정은 제안이고, 결정은 담당자가 합니다.
- **PC에서도, 사내 서버에서도**: 개발자 PC에 설치해 쓰지 않는 시간에 예약 점검하거나, 사내 서버에 두고 내부 서비스를 점검합니다. 로그인 정보는 에이전트를 떠나지 않습니다.
